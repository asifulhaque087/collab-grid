# CollabGrid — Agent Guide

## Quick Commands

**API (Go) — from `api/`:**
```bash
make watch   # hot reload via Air
make run     # go run cmd/main.go
make build   # builds bin/api + bin/seed
make seed    # run database seeder
```

**Web (Next.js) — from `web/`:**
```bash
pnpm dev              # :3000
pnpm build
pnpm lint             # eslint --max-warnings 0
pnpm check-types      # next typegen && tsc --noEmit
```

**Database / SQLC — from `api/`:**
```bash
sqlc generate         # regenerates sqlc/ from queries/*.sql
```

**Validate (CI order):**
```bash
cd api && go build ./... && go vet ./...
cd web && pnpm lint && pnpm check-types
```

## Stack

Go 1.25 · pgx/v5 · sqlc · chi/v5 · casbin/v2 · JWT  
Next.js 16 · Tailwind v4 (CSS `@theme`, **no** `tailwind.config.js`) · shadcn/ui · socket.io-client

## API Architecture (Go)

```
cmd/main.go              entrypoint → config → pg pool → module → server
internal/
  app/server.go          chi.NewMux, middleware.Logger/Recoverer, Start(port)
  module/
    contract.go          Module interface { RegisterRoute(r chi.Router) }
    app.go               wire up: repo.New(pool) → auth.NewService → auth.NewHandler → routes
    test.module.go       same shape but uses FakeRepo + FakeLimitGuardQueries + memUoW
  service/auth/          handler, service, middleware, e2e_test, repo.fake, limit_guard.fake
  adapters/postgresql/
    sqlc/                GENERATED by sqlc — never edit by hand
    queries/             *.sql → sqlc input (edit these, run `sqlc generate`)
    migrations/          *.sql (NOT auto-applied on boot)
    casbin.go            InitCasbinEnforcer — pg adapter
    casbin.fake.go       InitFakeCasbinEnforcer — in-memory policies (hardcoded for tests)
  domain/                AuthRepo interface, UnitOfWork (Stores struct + RunInTx)
  config/                env via caarlos0/env + godotenv + validator (20+ required vars)
                         CasbinModelConf embedded via //go:embed model.conf
```

Routes are grouped under `/auth`:
- **Public:** `POST /register`, `GET /google`, `GET /google/callback`
- **Protected** (JWTMiddleware → CasbinMiddleware → LimitGuard): `GET /demo`, `POST /demo`, `DELETE /demo`

## Key Patterns

| Pattern | Detail |
|---------|--------|
| **Router** | chi/v5 — use `r.Route()`, `r.Group()`, `r.Use()` |
| **Middleware chain** | JWTMiddleware (injects `*JwtPayload` via `UserContextKey`) → CasbinMiddleware (tenantID, pattern, method) → LimitGuard (usage quota via subscription limits) |
| **User extraction** | `GetUserFromContext(r.Context())` returns `*JwtPayload` with `ID`, `PrimaryUserID`, `SecondaryUserID` |
| **LimitGuard** | `LimitGuardQueries` interface (7 methods) — production uses `*repo.Queries`, tests use `FakeLimitGuardQueries`. Lookup always targets POST permission row; POST increments, DELETE decrements |
| **Testing (API)** | `module.NewTestModule()` creates fakes. `app.NewServer(router, testModule)`. `httptest.NewServer(r)`. Register user to get JWT, seed `FakeLimitGuardQueries` + `Enforcer.AddPolicy()` for protected route tests. See `e2e_test.go` |
| **FakeRepo** | Embeds `repo.Querier` (unused methods fall through). Thread-safe via `sync.RWMutex`. `Reset()` for test isolation. `newUUID()` from `crypto/rand` |
| **memUoW** | `domain.Stores{Auth: t.AuthRepo}` + inline `RunInTx` that calls `fn(stores)` directly (no real transaction) |
| **Casbin in tests** | `InitFakeCasbinEnforcer()` from `casbin.fake.go` — no DB adapter, seed policies + role mappings inline. Exposed as `TestModule.Enforcer` |
| **UoW (prod)** | `postgresql.UoW` wraps pgx transactions; stores created via `tx.Auth = repo.New(tx).Queries` |
| **sqlc workflow** | Edit `queries/*.sql` → `sqlc generate` → generated code lands in `sqlc/` |
| **Env** | `api/.env` requires 20+ vars (DB, JWT secrets, Redis, RabbitMQ, OAuth, SMTP). Docker compose overrides Redis + RabbitMQ URLs |
